# 开发者想对你们说的话

各位小鸽子们，大家好！这里是铃萤哦！

感谢你使用 Arkiroku！不知道各位小鸽子们这一段时间使用下来的体验怎么样呢？

就在写下这些话的时候，铃萤刚刚完成了主线第九章更新的第二部分，首先铃萤必须吐槽一句：这个触摸阻挡机制的创意真的很创人，如果不是看到其他人的总结铃萤根本不知道按下那里是不能触发判定的！打完 Petrichor 之后发现在 1437 个 Perfect 的判定之下居然只获得了 35 万分！

但当铃萤看到主线剧情的最后，鸠鸠和 Gino 贴贴的那一幕的时候，铃萤才真正意识到她所投入全身心服务的是一个怎样的游戏，以及一个怎样的社区。

如果用一句话来表达铃萤最真实的想法，那就是：非常荣幸能够为这样一款铃萤心目中最好的音乐游戏和紧紧围绕着她的这个充满生机与活力的社区服务！

铃萤想对各位小鸽子们说的话很多很多，但铃萤只能一件事一件事说。

首先，铃萤想讲一讲她为什么会选择去开发并持续维护这样一款查分工具，也就是 Arkiroku。

## 为什么要开发 Arkiroku？

其实这不是铃萤第一次为 Phigros 的玩家社区服务了。

早在两年之前，铃萤就曾为一个规模达到 2000 人的 Phigros 交流群提供了四个多月的查分 Bot 服务。

那段时间，“樱璃 Bot” 不仅为那个 Phigros 交流群提供了服务，事实上，在那个时候，樱璃的存在已经覆盖了二三十个 Phigros 交流群，处理的玩家存档数一度达到 7526 条。

但随着服务范围的扩大，原本只有 4M 小水管带宽的轻量应用服务器逐渐变得无法负担这样的负载，且铃萤也实在因为大学学业的原因逐渐无力继续维护，因此铃萤在和最初的用户们沟通后，选择停止继续提供服务，铃萤开始转而为另一个 Bot 提供技术与维护支持，那个 Bot，就是云露露 Bot。

在继续提供技术支持的时期，铃萤面对的是一个逐步收紧的 QQ Bot 生态，她和皮梦一起在这个摇摇欲坠的野生 Bot 生态中苦苦挣扎，虽然现在依然在持续运营，但时不时也会遇到很多麻烦，例如一个 Bot 号突然被封掉等等大大小小的问题。

在那时候，铃萤开始了思考：如果铃萤能够拿出一个不依赖 QQ Bot 的查分方案，让小鸽子们的查分不再被 QQ 的生态限制，那么以她的能力，她能做到怎样的成果？

但还是由于铃萤的学业问题，她已经脱离 Phigros 的玩家社区很久了，根本不清楚社区的发展情况，她也已经很久不玩 Phigros 了，因此她实际上对 Phigros 的理解非常落后，在 26 年 1 月回归前，她的记忆一直停留在与范式起源的联动。

铃萤在今年二月份看到有人还在讨论樱璃 Bot，那个在她脑海里沉寂已久的思考再次浮现上来，她又对自己问出了那个问题：她是否能够提供一个不依赖 QQ 生态的查分工具？

于是她给出了这样的回答：用 Jetpack Compose 结合原生的 Material Design 3 设计，在 Android 实现一个简洁、美观、易用和功能全面的查分器。事实证明，她最后做到了。

2026 年 2 月 23 日，第一行代码开始出现在她的电脑中，2 月 24 日，第一个 Public Beta Release 版本发布。那时候的 Arkiroku 非常简陋，很多功能刚刚起步，现在的 Arkiroku 的很多功能在当时仅仅停留在铃萤的开发计划中，或者仅仅停留在铃萤的构思之中。

随着一个又一个开发计划的形成，一个又一个功能的实现，无数次编译与打包，以及一次持续了四个月的大规模重构之后，Arkiroku 终于能够回答铃萤最开始的那个问题：她可以做到，并且做到了。

这就是铃萤决定开发 Arkiroku 的原因了。下一个：

## Arkiroku 的名字是怎么来的？

Arkiroku 最开始的名字是 Phi Tracker，这个名字非常简单且明了，因为各位小鸽子们一眼就能看出来这是一款为 Phigros 提供的社区工具。

但 Phi Tracker 过于直白了，铃萤一直觉得这个名字不适合长期使用，但由于已经形成了稳定的开发流程，因此她一直保留着 Phi Tracker 的名字。

直到鸽游的同人创作规范公布的那一天，她意识到：她需要为这个项目改一个名字了。

在思考新的名字的时候，有两个名字最后让铃萤感觉到眼前一亮：Phiroku 和 Arkiseki。Phiroku 取的是 Phi+Kiroku(記録)的组合，而 Arkiseki 是 Ark(方舟)+Kiseki(軌跡、奇跡)的组合。

但铃萤认为 Phiroku 的名字还是会容易与 Phigros 混淆，因此她并没有选择这个名字；并且，铃萤认为，Kiseki 的形容应该属于 Phigros：

Phigros 作为一款非商业的公益游戏，在面对重重困难与危机的时候，鸽游也没有想过放弃她的开发，小鸽子们也大力支持鸽游，通过购买 Rizline 的曲包和鸽游的周边来持续支持鸽游的开发。

因此，Phigros 本身就是最大的 Kiseki，而铃萤唯一需要做的，就是忠实地 Kiroku 这个 Kiseki。

铃萤最后选择了将 Ark 与 Kiroku 结合，于是就有了 Arkiroku。

## 为什么 Arkiroku 在八个月的时间内一直没有正式发出稳定版？

虽然铃萤会在每一个版本开发工作的开始前拟订一个覆盖整个版本开发过程的开发计划，但是铃萤在拟订开发计划的时候往往没有想到一些她认为适合加入进来的功能，因此她的开发计划往往最终都是 120% 完成的。

并且，铃萤认为，一个合格的稳定版 Arkiroku 必须是她心里认为最完美的版本，在那个版本中，铃萤再也想不到有什么功能没有实现，那个版本的体验也已经找不到任何可以进一步优化的点，但现在的版本依然还有很多功能没有实现。

虽然铃萤也想在 Phigros 的第九章二阶段更新之前将正式版发出，但最近的开发工作还没有完成，铃萤无法容忍将一个半成品匆忙拿出来作为正式版，因此她放弃了追赶的计划，转而继续开始打磨体验，最近的一次成果是加入了开场引导，让各位小鸽子们可以在第一次使用时就将 Arkiroku 调整到最适合自己的样子。

铃萤会在她认为应该实现的所有功能都得到实现后，才发出第一个正式版，各位小鸽子们可以再期待一下哦！

## Phigros 的主线已经完结，Arkiroku 还会再继续开发吗？

会！

Arkiroku 的开发不会随着 Phigros 主线的完结而结束，Phigros 主线剧情的完结象征着 Phigros 一个时期的结束，但 Phigros 作为由鸽游与玩家们共同塑造的 Kiseki，铃萤相信她的故事绝不会因此完结。

Arkiroku 会持续围绕 Phigros 推出更多实用的功能，继续为了铃萤在 README 中写下的那个目标：“成为一款功能全面、易用、简洁且美观的 Phigros 查分工具，让玩家能够方便地查看自己的游戏数据，并在现有的 QQ Bot 查分解决方案之外，提供另一种选择”而努力！

在 Phigros 彻底停止运营之前，Arkiroku 的开发不会停止！铃萤会继续与各位小鸽子们一起为这个繁荣的玩家社区贡献出属于她自己的一份力量哦！

名为 Phigros 的 Kiseki，将一直闪耀下去！

## 在故事最后的最后

在很久很久以前，Phigros 的小鸽子们用自己的勤劳与智慧，用一张张看似简单的 Excel 表，支撑了这个社区中对查分的需求。

后来，有一群人开辟了一块名为 Phi-Plugin 的大陆，在那块大陆上，生活着文酱、怵酱、圈圈、steve、⑨酱、滢、哒哒哒、陌离、废酱还有各位小鸽子们；一段时间后，在那个叫做 Phi-Plugin 的大陆上，又搬来了酒精、弦塔、皮梦、阿萤、寒宇、茗亿、千奈千祁还有好多好多新的小鸽子们。

在此之后，Phigros Query 和 Phi-Plugin Next 的出现，为 Phigros 的查分提供了一种全新的路线，QQ Bot 以外的查分方式第一次成为现实。

再后来，Qianmo 带着他的 RankHub，为各位小鸽子们展示了另一种全新的可能，原来 Phigros 的查分也可以自己完成，铃萤也希望用 Arkiroku，实现她自己的那一个小小的愿望，为了这个キラキラ的社群和各位可爱的小鸽子们，将这个 Kiseki 持续下去。

现在，rRanker 和 Phi Score Query 等星火也破土而出，还有更多的星星正在赶来的路上......

“星河浩瀚，长路且阻，回顾这一切，你又会想起什么？”

铃萤想到的，是她 21 年初次入坑 Phigros，是为了推 Glaciaxion 的 AP 而不断重开的那个晚上，是她达成 RKS 11 解锁所有 IN 难度的兴奋，是她在 22 年的梦魇中迎来的第七章主线更新，是她用樱璃 Bot 初次为社区服务的那一天，是她回归之后看着 Phigros 的联动规模逐步扩大的欣慰，是她发布第一个 Arkiroku 时的激动......

Arkiroku，就是铃萤为 Phigros 的最终献礼，也是回答鸽游在第九章提出的这个问题的最终答案。

鸠鸠与 Gino 的重逢，为 Phigros 的故事画下了一个完美的注解。

现在，Phigros 的故事，就依赖各位小鸽子们来共同书写啦！
